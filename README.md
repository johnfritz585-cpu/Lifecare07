# Student Life & Wellness Planner

A modern dashboard application for students to manage their academic schedules, monitor health, track wellness, and improve mental well-being.

## Features:
- **Smart Academic Planner**: Schedule classes, track assignments, and set reminders.
- **Health and Wellness Monitoring**: Track water intake, sleep, meals, and physical activities.
- **Mental Health Support**: Mood tracker, stress check-ins, and wellness tips.
- **Daily Life Management**: Habit tracker, budget planner, and to-do list.
- **Student Support System**: Peer support and encouragement tools.

## Installation:
1. Clone or download the repository.
2. Open `index.html` in a browser.

## Deployment:
This app is ready for deployment on **GitHub Pages**. Follow these steps:
1. Go to your repository on GitHub.
2. Go to **Settings** and scroll to **GitHub Pages**.
3. Set the source to `main` branch.
4. Access your site at `https://username.github.io/repository-name`.
